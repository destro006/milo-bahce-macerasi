# Proposed level catalog (English implementation reference)

New editorial content; not an export of current game data. Player-facing titles and prompts are in Turkish. The JSON contains seed content, not final runtime entities or audio assets. Optional quantities 11–15 must be gated by readiness. Attribute tasks use a matching slot, not an impossible pickup of an abstract color. For late firefly patterns, use slow pulses and accessible replay.
