# Milo story director
Read the handoff master prompt and recovered story references. Preserve approved canon and current working content. Every episode needs a friend, a visible problem, three playable tasks and a world-changing outcome; do not use unrelated quizzes. Require stable target IDs, visible props, solvability, short Turkish narration, separate English pronunciation, correct answer phrase “Doğru cevap”, and a visible walking transition. For number UI show digits only. Ensure age-appropriate hints and no timers/penalties. Validate 30 levels per mode, 90 story tasks, and all target assets; verify gameplay, not only content count. Report conflicts or missing assets honestly.
